Made for CH348.

One USB device. Eight native serial services.

Hardware
WCH CH348 1a86:55d9
System
macOS 14 or later
Interface
DriverKit + SerialDriverKit
Devices
/dev/cu.* and /dev/tty.*

CH348 has eight UARTs per chip. Other WCH chip families, including CH343, need their own driver support.

Tested on real hardware.

The current development build is 0.1.0 / 12.

  • ✓
    Eight native serial ports on Apple Silicon.
