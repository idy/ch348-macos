Made for CH348.

One USB device. Eight native serial services.

Hardware
WCH CH348 1a86:55d9
System
macOS 14 or later
Interface
DriverKit + SerialDriverKit
Devices
/dev/cu.* and /dev/tty.*

CH348 has eight UARTs per chip. Other WCH chip families, including CH343, need their own driver support.

Tested on real hardware.

Hardware smoke tests were recorded with 0.1.0 / 12.

  • ✓
    Eight native serial ports on Apple Silicon.
  • ✓
    Driver replacement after a physical reconnect.
  • ✓
    H2Loader command exchange through native ports.

Intel runtime, simultaneous multi-adapter use, sustained throughput, sleep and reboot still need qualification.
